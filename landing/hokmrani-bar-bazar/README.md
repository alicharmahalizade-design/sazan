# لندینگ «دوره جامع حکمرانی بر بازار»

صفحه فرود تک‌صفحه‌ای، راست‌به‌چپ و کاملاً ریسپانسیو، هم‌راستا با هویت بصری سازان
(primary `#00b6f1` · secondary `#f7941d` · base `#000014`).

## ساختار فایل‌ها

```
landing/hokmrani-bar-bazar/
├── index.html            # کل محتوای صفحه
└── assets/
    ├── css/style.css     # استایل (بدون وابستگی خارجی)
    └── js/main.js        # تعاملات (وانیلا، بدون کتابخانه)
```

تنها منبع خارجی صفحه، فونت **Vazirmatn** از Google Fonts است. برای اجرای آفلاین
یا حذف وابستگی، فونت را لوکال کنید و تگ `<link>` مربوط به `fonts.googleapis.com`
را در `index.html` با `@font-face` جایگزین کنید. فونت‌های جایگزین (`IRANSans`,
`Tahoma`) از قبل در استایل تعریف شده‌اند.

## بخش‌های صفحه

هیرو · مدت و نوع دوره · مسیر اجرایی · سؤال بزرگ · چرایی رشد · سرفصل‌ها (۷ محور)
· تفاوت اصلی دوره · اسکن کسب‌وکار و جلسات خصوصی · ساختار دو لایه · مناسب چه کسی
· نتایج دوره · جمع‌بندی · فرم ثبت درخواست · سوالات متداول · پاورقی

## تعاملات

- هدر چسبان با تغییر حالت هنگام اسکرول و منوی همبرگری در موبایل
- نمایش تدریجی بخش‌ها با `IntersectionObserver`
- شمارنده اعداد هیرو با ارقام فارسی
- آکاردئون سوالات متداول (هم‌زمان فقط یک سوال باز می‌ماند)
- اعتبارسنجی فرم ثبت درخواست (نام + موبایل، با پذیرش ارقام فارسی و عربی)
- دکمه بازگشت به بالا و نوار CTA چسبان در موبایل
- پشتیبانی از `prefers-reduced-motion`

## اتصال فرم به بک‌اند

فرم در حال حاضر سمت کلاینت اعتبارسنجی می‌شود و داده را ارسال نمی‌کند.
محل اتصال در `assets/js/main.js` با کامنت `TODO` مشخص شده است:

```js
var payload = { name, phone, business, note };
// اینجا: fetch به REST وردپرس، admin-ajax یا سرویس CRM
```

نمونه اتصال به REST وردپرس:

```js
fetch('/wp-json/szp/v1/course-request', {
	method: 'POST',
	headers: { 'Content-Type': 'application/json', 'X-WP-Nonce': window.SZP_NONCE },
	body: JSON.stringify(payload)
});
```

> در سمت سرور حتماً nonce را بررسی کنید، ورودی‌ها را sanitize کنید و
> محدودیت نرخ ارسال (rate limit) بگذارید.

## نکات محتوایی

- پاسخ‌های بخش «سوالات متداول» از متن خودِ دوره استخراج و نگارش شده‌اند
  (در متن اولیه فقط عنوان سوال‌ها آمده بود). پیش از انتشار بازبینی شوند.
- دو غلط تایپی متن اولیه اصلاح شد: «ارتباط حرف‌ه‌ای‌تر» → «ارتباط حرفه‌ای‌تر»
  و «نتایج دو‌ره چیست؟» → «نتایج دوره چیست؟».
