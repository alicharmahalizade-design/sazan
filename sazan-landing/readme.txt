مجموعه ویجت‌های المنتور برای ساخت لندینگ «دوره جامع حکمرانی بر بازار»
با کنترل کامل متن‌ها و استایل‌ها، به‌همراه فرم ثبت درخواست حضور در دوره.

== توضیحات ==

این افزونه ۱۳ ویجت المنتور در دسته «سازان — لندینگ دوره» اضافه می‌کند.
هر ویجت با متن‌های واقعی دوره از پیش پر شده است؛ یعنی بلافاصله بعد از
درگ‌کردن، همان بخش آماده را می‌بینید و فقط جاهایی را که می‌خواهید عوض می‌کنید.

= ویجت‌ها =

1. لندینگ: هیرو — برچسب، عنوان، شعار، توضیح، دکمه‌ها و آمار دوره
2. لندینگ: کارت‌های مشخصات دوره — مدت دوره و نوع دوره
3. لندینگ: مسیر اجرایی — مراحل شماره‌دار با خط اتصال
4. لندینگ: گرید سؤال‌ها — سؤال‌های تصمیم‌گیری + بلوک سؤال محوری
5. لندینگ: دو ستون مقایسه — تلاش بیشتر / مسئله عمیق‌تر
6. لندینگ: سرفصل‌های دوره — ۷ محور آموزشی
7. لندینگ: تیم دوره — مدرس، کوچ و منتور
8. لندینگ: گرید محورها — محورهای کاری جلسات خصوصی
9. لندینگ: ساختار لایه‌ای — لایه آموزش و لایه کوچینگ
10. لندینگ: لیست تیک‌دار — «مناسب شماست اگر…» یا جمع‌بندی
11. لندینگ: نتایج دوره — کارت‌های شماره‌دار
12. لندینگ: فرم ثبت درخواست — بلوک CTA + فرم
13. لندینگ: سوالات متداول — آکاردئون + اسکیمای FAQPage

= تنظیمات استایلی هر ویجت =

* **پالت رنگ** — رنگ اصلی، مکمل، متن، عنوان، متن کم‌رنگ، سطح کارت، حاشیه
  و سه رنگ گرادیان با زاویه قابل تنظیم. این کنترل‌ها متغیرهای CSS ویجت را
  می‌نویسند، پس یک تغییر رنگ کل بخش را هماهنگ عوض می‌کند.
* **تایپوگرافی** — برای تک‌تک عناصر متنی (عنوان، زیرعنوان، برچسب، متن،
  لیست، جمله تأکیدی و…) به‌صورت جدا.
* **کادرها** — پس‌زمینه (ساده یا گرادیانی)، حاشیه، گردی گوشه، فاصله داخلی و سایه.
* **چیدمان** — تعداد ستون‌ها به‌تفکیک دسکتاپ/تبلت/موبایل، فاصله بین ستون‌ها،
  فاصله داخلی بخش، تراز متن و جهت (راست‌به‌چپ یا چپ‌به‌راست).
* **دکمه‌ها** — استایل جداگانه برای حالت عادی و هاور.

== فرم ثبت درخواست ==

درخواست‌ها در نوع محتوای `szl_request` ذخیره می‌شوند و از منوی
«درخواست‌های دوره» در پیشخوان قابل مشاهده‌اند. خروجی CSV هم از همان صفحه
گرفته می‌شود (با BOM، تا اکسل فارسی را درست باز کند).

هر ثبت یک ایمیل به مدیر سایت می‌فرستد. برای تغییر این رفتار:

`add_filter( 'szl_notify_admin', '__return_false' );`
`add_filter( 'szl_notify_email', function () { return 'sales@example.com'; } );`

برای اتصال به CRM یا پنل پیامک:

`add_action( 'szl_request_saved', function ( $post_id, $data ) {`
`    // $data = array( 'name', 'phone', 'biz', 'note', 'src' )`
`}, 10, 2 );`

= محافظت‌های فرم =

* بررسی nonce روی هر درخواست
* honeypot پنهان برای ربات‌ها
* محدودیت ۵ ثبت در ساعت برای هر IP
* پذیرش ارقام فارسی و عربی در شماره موبایل و نرمال‌سازی به `09xxxxxxxxx`
  (فرمت‌های `+98`، `0098`، `98` و شماره با فاصله یا خط تیره هم پذیرفته می‌شود)

== نصب ==

1. پوشه `sazan-landing` را در `wp-content/plugins/` قرار دهید.
2. افزونه را فعال کنید (المنتور باید از قبل نصب و فعال باشد).
3. در ویرایشگر المنتور، دسته «سازان — لندینگ دوره» را باز کنید.

== یادداشت‌ها ==

* فونت صفحه از قالب سایت به ارث می‌رسد؛ افزونه فونتی بارگذاری نمی‌کند.
  برای فارسی، فونت Vazirmatn پیشنهاد می‌شود.
* پاسخ‌های پیش‌فرض بخش «سوالات متداول» از متن دوره نگارش شده‌اند؛
  پیش از انتشار بازبینی کنید.
* اسکیمای FAQPage فقط روی یک ویجت سوالات متداول در هر صفحه روشن بماند.
