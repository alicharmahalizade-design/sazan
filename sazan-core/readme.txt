=== Sazan Core ===
مجموعه ویجت‌های اختصاصی المنتور (سازان).

== ویجت‌ها ==
- هدر سازان (sazan-header)
- اسلایدر هیرو سازان (sazan-hero) — سه طرح قابل سوییچ
- نوار چرخان سازان (sazan-marquee)
- دوره‌های سازان + فیلتر (sazan-courses)
- تقویم آموزشی سازان (sazan-calendar)
- پادکست سازان (sazan-podcast)
- وبلاگ سازان (sazan-blog)
- اسلایدر دوره سازان / پوستری (sazan-product-slider)
- تیتر سازان (sazan-heading) — نمونه

== نصب ==
فایل zip را از «افزونه‌ها > افزودن > بارگذاری افزونه» آپلود و فعال کنید
(المنتور باید فعال باشد). دسته‌بندی «سازان» در پنل ویجت‌ها ظاهر می‌شود.

== نکته ==
- بخش‌های دارک‌مود (دوره/تقویم/پادکست/وبلاگ) رنگ پیش‌فرض تیره دارند؛ همه‌ی
  رنگ‌ها از تب «استایل > پالت رنگ» قابل تغییرند.
- فیلتر دوره‌ها: مقدار «کلید دسته» هر دوره را با «کلید فیلتر» چیپ‌ها یکی کنید.

== اسلایدر دوره سازان: صحنه‌ی نورپردازی‌شده + کارتِ آرام‌تر — نسخه 3.31.1 ==
* بلوکِ آبیِ خالی به «صحنه‌ی نورپردازی‌شده» تبدیل شد: نورِ صحنه و هاله‌ی حلقه‌ای
  پشتِ پوستر، حباب‌های نرمِ نور (bokeh)، گرادیانِ مش و سایه‌ی کفِ سوژه — عمق و فضاسازی.
* کارت شلوغی‌اش کم شد: چیپ‌ها و جعبه‌های تایمر ریزتر، نوارِ ظرفیت نازک‌تر،
  ریتمِ فاصله‌ها منظم‌تر و قیمت به‌عنوانِ نقطه‌ی کانونی کمی درخشان‌تر شد.

== اسلایدر دوره سازان: افکت شیشه‌ای — نسخه 3.31.0 ==
* گلس‌مورفیسم: کارتِ دوره حالا شیشه‌ایِ مات (frosted glass) با backdrop-filter blur است.
* کنترلِ استایلِ «✨ افکت شیشه‌ای»: روشن/خاموش + شدتِ بلر + ته‌رنگِ شیشه + رنگِ لبه.
* چیپ‌ها، جعبه‌های تایمر، نوارِ ظرفیت و آواتارِ مدرس هم شیشه‌ای شدند + درخششِ لبه‌ی کارت.
* fallback برای مرورگرهای بدونِ backdrop-filter (ته‌رنگِ کدرترِ خوانا).

== اسلایدر دوره سازان (پوستری) — نسخه 3.30.0 ==
* ویجت «اسلایدر محصول» به «اسلایدر دوره» تبدیل شد؛ همه‌ی فیلدها آموزشی شدند:
  - چیپ‌های مشخصات دوره به‌جای گزینه‌های سایز (۱۲ جلسه · ۹۶ ساعت · سطح · پشتیبانی) با آیکن.
  - قیمت با تخفیف: قیمتِ قبلیِ خط‌خورده + قیمتِ جدید + بَجِ درصد.
  - دکمه‌ها: «ثبت‌نام دوره» و «دریافت سرفصل‌ها/مشاوره رایگان» (با لینک و آیکن دلخواه).
  - گیج «رضایت هنرجو/ظرفیت تکمیل‌شده».
* افزوده‌ها: دکمه‌ی پخشِ تیزر روی پوستر → پاپ‌آپ ویدیو (آپارات/یوتیوب/mp4)،
  بلوکِ مدرس (عکس+نام+تخصص)، امتیاز ستاره‌ای + تعداد هنرجو، ربانِ گوشه
  (جدید/تخفیف/پرطرفدار)، نوارِ پیشرفتِ ظرفیت، پارالاکسِ پوستر با موس + Ken Burns.
* منبعِ خودکار: اتصال به دوره‌های واقعیِ سایت (هر نوع‌پست یا محصولِ ووکامرس)
  با نگاشتِ عنوان/تصویر/قیمت‌وتخفیف/لینک و درصدِ گیج از متا.
* تایمرِ شمارش معکوس برای مهلتِ ثبت‌نام (مثل قبل) حفظ شد.

== آزمون سازان (Sazan Quiz) — نسخه 3.12.0 ==
* پست‌تایپ «آزمون‌ها»: ساخت آزمون با محور، سوال (تک/چند/طیفی) و امتیاز هر گزینه.
* امتیازدهی: «مجموع/درصدی ساده» یا «چندمحوری» (نمودار رادار).
* بازه‌های امتیاز: پیام مشاوره‌ای + توضیحات + محصولات پیشنهادی ووکامرس + دکمه اقدام.
* گرفتن لید (نام/موبایل/ایمیل/شرکت) قبل از نمایش نتیجه + ذخیره در جدول اختصاصی.
* داشبورد «نتایج و لیدها» + اکسپورت CSV.
* نمایش: ویجت «آزمون سازان» در المنتور یا شورت‌کد [sazan_quiz id="..."].

= اتصال پنل پیامک =
نمونه برای کاوه‌نگار (در functions.php قالب):

add_action( 'sazan_quiz_send_sms', function ( $mobile, $text ) {
    $api = 'KAVENEGAR_API_KEY';
    wp_remote_post( "https://api.kavenegar.com/v1/{$api}/sms/send.json", array(
        'body' => array( 'receptor' => $mobile, 'sender' => '10004346', 'message' => $text ),
        'timeout' => 15,
    ) );
}, 10, 2 );

= پیامک فراز اس ام اس (داخلی) =
از منوی «آزمون‌های سازان ← تنظیمات» کلید apikey، شماره فرستنده، حالت (پترن/متن آزاد) و کد پترن را وارد کن.
برای حالت پترن، پترن را با متغیرهای name / score / tier / link بساز.
یک صفحه با شورت‌کد [sazan_quiz_result] بساز و در همان تنظیمات به‌عنوان «صفحه نتیجه» انتخاب کن؛ لینک پیامک به این صفحه با ?token= اشاره می‌کند.

= کتابخانه‌های محلی (اختیاری) =
سه فایل Chart.js / jsPDF / html2canvas را در assets/quiz/lib/ بگذار تا به‌جای CDN لوکال لود شوند (راهنما در همان پوشه).

== فرم‌ساز سازان (نسخه 3.18.0) ==
- منوی «فرم‌ساز سازان»: ساخت فرم با کشیدن‌ودرکردن فیلدها (متن، موبایل، ایمیل،
  عدد، متن بلند، لیست کشویی، تاریخ شمسی)، تعیین کلید لاتین، عرض و اجباری‌بودن.
- اتصال به فراز اس ام اس: «تنظیمات پیامک» (کلید/فرستنده/شماره مدیریت) سراسری،
  و کد پترن «به مدیریت»/«به کاربر» در هر فرم. متغیرهای پترن = کلید لاتین فیلدها.
- تایید شماره با کد (OTP) اختیاری برای هر فرم.
- خروجی: شورت‌کد [sazan_form id="X"] (درون‌خطی) یا
  [sazan_form id="X" popup="yes" trigger="ثبت نام"] (دکمه‌ی پاپ‌آپ).
- ثبت‌ها در «ثبت‌های فرم» ذخیره و قابل خروجی CSV هر فرم هستند.
- تقویم آموزشی: هر ردیف می‌تواند دکمه‌ی ثبت‌نام را به‌صورت «پاپ‌آپ فرم» یا
  «رفتن به صفحه‌ی فرم» تنظیم کند (علاوه بر لینک دلخواه).

== اسلایدر هیرو سازان (نسخه 3.19.0) ==
ویجت جدید «اسلایدر هیرو سازان» با چند طرح قابل سوییچ از یک محتوای مشترک:
- طرح ۱ (برند فردی / سبک حسین‌طاهری): پرتره‌ی کناری با حلقه‌های رادار و نام روی
  عکس، چیپ‌های ویژگی، نشان دوره، و «پیک» (لبه‌ی اسلایدهای قبل/بعد دیده می‌شود).
- طرح ۲ (آکادمی / سبک ایران برند آکادمی): تصویر یک‌سمت ثابت می‌ماند و فقط متن
  اسلایدها (عنوان دوخطی درشت + توضیح) اسلاید می‌شود؛ همراه قاب گوشه‌ای.
- طرح ۳ (تلفیقی): ترکیب پرتره + چیپ‌ها + امتیاز + نوار آمار.
- امکانات: پخش خودکار، فلش/نقطه، جلوه کشویی یا محو، سوایپ لمسی، ریسپانسیو کامل،
  و همه‌ی رنگ‌ها از «استایل ← پالت رنگ» (متغیرهای --sz-*) هماهنگ با تم سازان.

== طرح ۴ اسلایدر هیرو: مینیمال (نسخه 3.20.0) ==
- طرح چهارم «مینیمال / خلوت»: تایپوگرافی درشت و خلوت، فقط یک واژه‌ی هایلایت و یک
  دکمه‌ی اصلی، شماره‌ی بزرگ توخالی به‌عنوان امضای بصری، و نوار پیشرفت باریک
  به‌جای نقطه‌ها. در این طرح چیپ‌ها به‌صورت پیش‌فرض نمایش داده نمی‌شوند تا خلوت بماند.

== طرح ۵ اسلایدر هیرو: خیلی مینیمال (نسخه 3.21.0) ==
- طرح پنجم «خیلی مینیمال / وسط‌چین»: چیدمان تک‌ستونه و وسط‌چین، فقط عنوان بزرگ،
  یک خط توضیح و یک دکمه؛ همراه شمارنده‌ی ظریف (۰۱ —— ۰۳) به‌جای نقطه‌ها.
- عکس (در صورت وجود) به‌صورت پس‌زمینه‌ی محو با روکش تیره پشت متن می‌نشیند.
- چیپ‌ها/آمار/امتیاز/فلش‌ها در این طرح نمایش داده نمی‌شوند تا کاملاً خلوت بماند.

== اسلایدر هیرو: جلوه‌ها و اتصال‌ها (نسخه 3.22.0) ==
- Ken Burns: زوم/حرکت بسیار آرام روی تصویر (و پس‌زمینه‌ی طرح ۵)؛ حس سینمایی.
  روی تصویر ثابت طرح ۲ اعمال نمی‌شود و به prefers-reduced-motion احترام می‌گذارد.
- پارالاکس موس: جابه‌جایی ظریف پرتره/هاله/رادار با حرکت نشانگر (فقط دسکتاپ).
- شمارش معکوس: تایمر روز/ساعت/دقیقه/ثانیه تا «تاریخ پایان» (کنترل تاریخ در پنل)،
  با متن دلخواه پس از پایان مهلت.
- اتصال دکمه‌ی اصلی: «لینک معمولی» یا «باز کردن فرم سازان (پاپ‌آپ)» با شناسه‌ی فرم،
  یا «پاپ‌آپ شورت‌کد» برای نمایش کوئیز سازان و هر شورت‌کد دیگری داخل مودال.

== طرح ۶ اسلایدر هیرو: بنر تصویری (نسخه 3.23.0) ==
- طرح ششم «بنر تصویری»: هر اسلاید فقط یک تصویرِ آماده است (بنر را خودت طراحی و
  آپلود می‌کنی)؛ بدون هیچ متن/چیپ/آمار روی آن. لینک اختیاری روی هر تصویر.
- «پیک» فعال است تا لبه‌ی اسلایدهای قبل/بعد پشت بنر فعال دیده شود (مثل نمونه).
- برای بهترین نتیجه، همه‌ی بنرها را با نسبت‌ابعاد یکسان بساز.
