=== Sazan Core ===
مجموعه ویجت‌های اختصاصی المنتور (سازان).

== ویجت‌ها ==
- هدر سازان (sazan-header)
- اسلایدر هیرو سازان (sazan-hero) — سه طرح قابل سوییچ
- نوار چرخان سازان (sazan-marquee)
- دوره‌های سازان + فیلتر (sazan-courses)
- تقویم آموزشی سازان (sazan-calendar)
- پادکست سازان (sazan-podcast)
- وبلاگ سازان (sazan-blog)
- اسلایدر دوره سازان / پوستری (sazan-product-slider)
- خدمات ما سازان / شیشه‌ای (sazan-services)
- سکشن پادکست سازان (sazan-podcast-section)
- تیتر سازان (sazan-heading) — نمونه

== نصب ==
فایل zip را از «افزونه‌ها > افزودن > بارگذاری افزونه» آپلود و فعال کنید
(المنتور باید فعال باشد). دسته‌بندی «سازان» در پنل ویجت‌ها ظاهر می‌شود.

== نکته ==
- بخش‌های دارک‌مود (دوره/تقویم/پادکست/وبلاگ) رنگ پیش‌فرض تیره دارند؛ همه‌ی
  رنگ‌ها از تب «استایل > پالت رنگ» قابل تغییرند.
- فیلتر دوره‌ها: مقدار «کلید دسته» هر دوره را با «کلید فیلتر» چیپ‌ها یکی کنید.

== آزمون سازان (Sazan Quiz) — نسخه 3.12.0 ==
* پست‌تایپ «آزمون‌ها»: ساخت آزمون با محور، سوال (تک/چند/طیفی) و امتیاز هر گزینه.
* امتیازدهی: «مجموع/درصدی ساده» یا «چندمحوری» (نمودار رادار).

* نمایش: ویجت «آزمون سازان» در المنتور یا شورت‌کد [sazan_quiz id="..."].

= اتصال پنل پیامک =
نمونه برای کاوه‌نگار (در functions.php قالب):

add_action( 'sazan_quiz_send_sms', function ( $mobile, $text ) {
    $api = 'KAVENEGAR_API_KEY';
    wp_remote_post( "https://api.kavenegar.com/v1/{$api}/sms/send.json", array(
        'body' => array( 'receptor' => $mobile, 'sender' => '10004346', 'message' => $text ),
        'timeout' => 15,
    ) );
}, 10, 2 );

= پیامک فراز اس ام اس (داخلی) =
از منوی «آزمون‌های سازان ← تنظیمات» کلید apikey، شماره فرستنده، حالت (پترن/متن آزاد) و کد پترن را وارد کن.
برای حالت پترن، پترن را با متغیرهای name / score / tier / link بساز.
یک صفحه با شورت‌کد [sazan_quiz_result] بساز و در همان تنظیمات به‌عنوان «صفحه نتیجه» انتخاب کن؛ لینک پیامک به این صفحه با ?token= اشاره می‌کند.

= کتابخانه‌های محلی (اختیاری) =
سه فایل Chart.js / jsPDF / html2canvas را در assets/quiz/lib/ بگذار تا به‌جای CDN لوکال لود شوند (راهنما در همان پوشه).

- طرح پنجم «خیلی مینیمال / وسط‌چین»: چیدمان تک‌ستونه و وسط‌چین، فقط عنوان بزرگ،
  یک خط توضیح و یک دکمه؛ همراه شمارنده‌ی ظریف (۰۱ —— ۰۳) به‌جای نقطه‌ها.
- عکس (در صورت وجود) به‌صورت پس‌زمینه‌ی محو با روکش تیره پشت متن می‌نشیند.
- چیپ‌ها/آمار/امتیاز/فلش‌ها در این طرح نمایش داده نمی‌شوند تا کاملاً خلوت بماند.

== اسلایدر هیرو: جلوه‌ها و اتصال‌ها (نسخه 3.22.0) ==
- Ken Burns: زوم/حرکت بسیار آرام روی تصویر (و پس‌زمینه‌ی طرح ۵)؛ حس سینمایی.
  روی تصویر ثابت طرح ۲ اعمال نمی‌شود و به prefers-reduced-motion احترام می‌گذارد.
- پارالاکس موس: جابه‌جایی ظریف پرتره/هاله/رادار با حرکت نشانگر (فقط دسکتاپ).
- شمارش معکوس: تایمر روز/ساعت/دقیقه/ثانیه تا «تاریخ پایان» (کنترل تاریخ در پنل)،
  با متن دلخواه پس از پایان مهلت.
- اتصال دکمه‌ی اصلی: «لینک معمولی» یا «باز کردن فرم سازان (پاپ‌آپ)» با شناسه‌ی فرم،
  یا «پاپ‌آپ شورت‌کد» برای نمایش کوئیز سازان و هر شورت‌کد دیگری داخل مودال.

== طرح ۶ اسلایدر هیرو: بنر تصویری (نسخه 3.23.0) ==
- طرح ششم «بنر تصویری»: هر اسلاید فقط یک تصویرِ آماده است (بنر را خودت طراحی و
  آپلود می‌کنی)؛ بدون هیچ متن/چیپ/آمار روی آن. لینک اختیاری روی هر تصویر.
- «پیک» فعال است تا لبه‌ی اسلایدهای قبل/بعد پشت بنر فعال دیده شود (مثل نمونه).
- برای بهترین نتیجه، همه‌ی بنرها را با نسبت‌ابعاد یکسان بساز.
