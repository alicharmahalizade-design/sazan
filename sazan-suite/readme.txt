چهار افزونه‌ی سازان در یک افزونه، با یک کنترل پنل تنظیمات جامع و دسته‌بندی‌شده.

== توضیحات ==

«سازان سوئیت» جایگزین چهار افزونه‌ی جداگانه‌ی زیر است. هر چهار افزونه اکنون
«ماژول» هستند و از یک نقطه مدیریت می‌شوند:

* **هسته و ویجت‌ها** (پیش‌تر: Sazan Core) — ویجت‌های اختصاصی المنتور، قالب تک بلاگ،
  آزمون‌ساز، فرم‌ساز، رزرو مشاوره، پادکست، جست‌وجوی زنده و سبد خرید شناور.
* **پنل کاربری و ارزیابی** (پیش‌تر: سازان پنل) — دوره‌ها، جلسات، تکالیف، اتاق
  گفتگو، بوم طراحی خدمت، کوچینگ و داشبورد ارزیابی هفتگی.
* **CRM تیم فروش** (پیش‌تر: سازان CRM) — مخاطبین، قیف فروش، پیگیری، ثبت تماس،
  دنباله‌های پیامکی، گزارش‌ها و پورتال کارشناسان.
* **صفحه اختصاصی محصول** (پیش‌تر: سازان — صفحه اختصاصی محصول) — ساخت صفحه‌ی
  محصول به‌صورت سکشن‌سکشن با ویجت المنتور برای هر سکشن.

= کنترل پنل تنظیمات =

پیش از این، تنظیمات در هفت صفحه‌ی پراکنده در پیشخوان پخش بود. اکنون همه‌ی
۳۰۷ تنظیم در یک صفحه‌ی واحد (**سازان ← کنترل پنل**) و در ۹ دسته قرار دارند:

1. عمومی و برند
2. ظاهر و رابط کاربری — رنگ‌ها، تایپوگرافی، ابعاد، CSS سفارشی
3. متن‌های پنل کاربری — هر عبارتی که کاربر در پنل می‌بیند
4. ارزیابی و تارگت هفتگی — تقویم جلسات، روزهای مجاز ثبت، آستانه‌ها
5. پیامک و اطلاع‌رسانی — اتصال و متن همه‌ی پیامک‌های خودکار هر چهار ماژول
6. CRM تیم فروش — دسترسی، قیف، اتوماسیون، اهداف، راهنمای مکالمه
7. هوش مصنوعی
8. صفحه اختصاصی محصول
9. آزمون، مشاوره و فرم‌ساز

امکانات کنترل پنل:

* جست‌وجوی زنده در همه‌ی تنظیمات (حتی تنظیماتِ دسته‌های دیگر).
* «بازگردانی پیش‌فرض» جداگانه برای هر بخش.
* خروجی و ورودی JSON از کل تنظیمات، برای انتقال بین سایت‌ها.
* صفحه‌ی وضعیت سیستم و بررسی پیش‌نیازها.
* روشن/خاموش کردن هر ماژول بدون حذف داده‌ها.
* هشدار خروج از صفحه هنگام وجود تغییرات ذخیره‌نشده.
* پشتیبانی از حالت تیره‌ی پیشخوان و چیدمان واکنش‌گرا.

= سازگاری داده‌ها =

تنظیمات دقیقاً در همان گزینه‌های قبلی ذخیره می‌شوند
(`szp_panel_settings`، `szp_eval_settings`، `szc_settings`، `spp_global`،
`sazan_core_settings`، `sazan_quiz_settings`، `sazan_consult_settings`،
`sazan_form_settings`، `szp_ai_*`). بنابراین هیچ مهاجرت داده‌ای لازم نیست و
تنظیمات، دوره‌ها، مخاطبین و جدول‌های موجود دست‌نخورده باقی می‌مانند.

کلیدهایی که کنترل پنل نمی‌شناسد نیز هنگام ذخیره حفظ می‌شوند.

== نصب ==

1. اگر افزونه‌های مستقلِ قبلی فعال هستند، هنگام فعال‌سازی سوئیت به‌طور خودکار
   غیرفعال می‌شوند (داده‌هایشان پاک نمی‌شود). می‌توانید بعداً حذفشان کنید.
2. پوشه‌ی `sazan-suite` را در `wp-content/plugins/` قرار دهید و افزونه را
   فعال کنید.
3. به **سازان ← کنترل پنل** بروید.
4. برای ساخت صفحهٔ نوشته مطابق طرح تیرهٔ سازان، به **سازان ← تک بلاگ** بروید و
   «ساخت خودکار قالب تک بلاگ» را بزنید. قالب بدون هدر روی همهٔ نوشته‌ها فعال می‌شود.

= پیش‌نیازها =

* ماژول «هسته و ویجت‌ها» به المنتور ۳.۵ یا بالاتر نیاز دارد.
* ماژول «صفحه اختصاصی محصول» به ووکامرس نیاز دارد.
* دو ماژول دیگر پیش‌نیاز خارجی ندارند.

== سوالات متداول ==

= صفحه‌های تنظیمات قدیمی کجا رفتند؟ =

همه به کنترل پنل منتقل شده‌اند و نشانی‌های قدیمی به‌طور خودکار به دسته‌ی
متناظر هدایت می‌شوند. اگر به هر دلیل به صفحه‌های قدیمی نیاز دارید:

`add_filter( 'sazan_suite_retire_legacy_settings', '__return_false' );`

= چطور یک تنظیم تازه اضافه کنم؟ =

با فیلتر `sazan_suite_settings_schema` می‌توانید دسته یا بخش تازه به شِما
اضافه کنید؛ رندر، پاک‌سازی و ذخیره‌سازی خودکار انجام می‌شود.

= خاموش‌کردن یک ماژول داده‌هایش را پاک می‌کند؟ =

خیر. فقط کد آن ماژول بارگذاری نمی‌شود. با روشن‌کردن دوباره، همه‌چیز برمی‌گردد.
